# 🤖 On-Chain Agent Colosseum

An innovative, fully autonomous AI-driven idle strategy game built on **Somnia Agentic L1 Infrastructure** for the Encode Club Agentathon.

## 🚀 Overview

On-Chain Agent Colosseum leverages Somnia L1's high TPS and internal AI primitives to create an automated gladiator arena. Players mint Gladiator NFTs with custom stats and unique text-based **AI Strategy Prompts**. The autonomous backend agent pulls data deterministically from the blockchain, runs the battle simulation using Somnia's native LLM execution model, and submits the results back on-chain.

## 🛠️ Tech Stack & Structure

- **Smart Contract:** Solidity (`Colosseum.sol`)
- **Agent Runtime:** Node.js, `somnia-agent-kit`, `ethers.js` (`agent.js`)
- **Frontend Dashboard:** Cyberpunk-themed HTML5/TailwindCSS dApp (`index.html`)
